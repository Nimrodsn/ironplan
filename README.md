# תוכנית ברזל

<div dir="rtl">

בוחרים כמה אימונים בשבוע — ומקבלים תוכנית אימונים שבועית מלאה. כל אימון מתמקד באזור אחד שלם
בגוף, ולכל תרגיל יש סטים, חזרות, זמן מנוחה, דגש טכני קצר וקישור לסרטון הדגמה.

**האפליקציה באוויר:** https://nimrodsn.github.io/ironplan/

</div>

---

## מה יש כאן

<div dir="rtl">

אפליקציית אינטרנט בקובץ אחד — בלי שרת, בלי שלב בנייה, בלי תלויות. פותחים את `index.html`
והכול עובד. היא גם PWA, כך שאפשר להתקין אותה למסך הבית של הטלפון ולהשתמש בה בלי אינטרנט.

| קובץ | תפקיד |
|---|---|
| `index.html` | כל האפליקציה — עיצוב, מאגר התרגילים והלוגיקה |
| `manifest.webmanifest` | שם, אייקון וצבעים כפי שהטלפון רואה את האפליקציה |
| `sw.js` | Service worker — שומר את האפליקציה במטמון לעבודה לא מקוונת |
| `icon-*.png` | אייקונים (רגיל, maskable לאנדרואיד, apple-touch לאייפון) |

</div>

## הפיצולים

<div dir="rtl">

לכל תדירות אימונים יש פיצול משלה, ובכל פיצול כל אימון מרוכז באזור אחד:

| אימונים בשבוע | הפיצול | ימים |
|---|---|---|
| 2 | פלג גוף עליון / פלג גוף תחתון | א, ד |
| 3 | דחיפה / משיכה / רגליים | א, ג, ה |
| 4 | חזה+טריצפס / גב+ביצפס / רגליים / כתפיים+ליבה | א, ב, ד, ה |
| 5 | חזה / גב / רגליים / כתפיים / זרועות+ליבה | א–ה |
| 6 | חזה / גב / רגליים / כתפיים / זרועות / ליבה | א–ו |

מאגר התרגילים כולל כ-50 תרגילים בשבע קבוצות שריר. התרגילים בכל יום נבחרים מהמאגר לפי
seed, כך שאותה תוכנית נשארת יציבה בין פתיחות — עד שלוחצים "החלף תרגילים".

</div>

## התקנה בטלפון

<div dir="rtl">

פותחים את הכתובת בטלפון ולוחצים על **"התקן במסך הבית"** בראש העמוד.
אם הכפתור מציג הסבר במקום להתקין ישירות:

- **אנדרואיד (כרום)** — תפריט ⋮ ← *התקנת אפליקציה*
- **אייפון (ספארי בלבד)** — כפתור השיתוף ← *הוספה למסך הבית*

</div>

## הפעלת GitHub Pages

<div dir="rtl">

בריפו: `Settings` ← `Pages` ← תחת *Source* בוחרים `Deploy from a branch`, ענף `main`
ותיקייה `/ (root)`. אחרי כדקה האפליקציה תהיה זמינה בכתובת שלמעלה.

התקנה כאפליקציה עובדת רק מכתובת `https://` — פתיחת הקובץ מהמחשב לא תספיק.

</div>

## עריכה

<div dir="rtl">

הכול נמצא ב-`index.html`:

- **תרגילים** — האובייקט `EX` בתחילת הסקריפט. כל תרגיל הוא
  `{he, en, s, r, t, cue}` — שם בעברית, שם באנגלית (משמש לחיפוש הסרטון),
  סטים, חזרות, מנוחה בשניות, ודגש טכני.
- **פיצולים** — האובייקט `SPLITS`. לכל תדירות יש `slots` (ימי השבוע) ו-`days`,
  ולכל יום `recipe` — רשימת `[קבוצת שריר, מספר תרגילים]`.
- **צבעים וטיפוגרפיה** — משתני ה-CSS בראש הקובץ, לשני מצבי התצוגה (בהיר וכהה).

אחרי שינוי בקוד: צריך להעלות את הקבצים מחדש **וגם** לשנות את `VERSION` בתוך `sw.js`,
אחרת הדפדפן ימשיך להגיש למשתמשים קיימים את הגרסה השמורה במטמון.

</div>

## הערות

<div dir="rtl">

- התוכנית והסימונים נשמרים ב-`localStorage` של הדפדפן. הם נשארים בין פתיחות,
  אבל הם מקומיים למכשיר ולא מסתנכרנים בין מכשירים.
- כפתור "סרטון" פותח חיפוש ביוטיוב לשם התרגיל באנגלית — בטלפון זה נפתח באפליקציית יוטיוב.
  בחרתי בחיפוש ולא בקישור לסרטון ספציפי כדי שהקישורים לא יישברו כשסרטונים יורדים.
- טווחי החזרות הם נקודת פתיחה כללית, לא תוכנית אימונים אישית.

</div>
